# Modern HTML 2026

**Практическое руководство по современному HTML и Web Platform**

HTML в современной веб-разработке — это не просто язык разметки и не «скелет» для JavaScript-приложения. Это декларативная основа Web Platform: HTML задаёт структуру и смысл интерфейса, предоставляет нативные механизмы взаимодействия и служит контрактом между браузером, пользователем, вспомогательными технологиями, поисковыми системами и программными инструментами.

Эта книга исследует современный HTML как полноценную технологию разработки интерфейсов: от семантики документа и встроенных интерактивных элементов до Web Components, производительности, SSR и архитектуры приложений.

Материал ориентирован на практику современной веб-разработки и актуальное состояние платформы в 2026 году.

---

## Зачем читать эту книгу

За последние годы браузеры получили нативные возможности, для которых раньше требовались сторонние библиотеки и значительные объёмы JavaScript: диалоговые окна, всплывающие слои, декларативные формы, управление загрузкой ресурсов, переходы между состояниями интерфейса и полноценная компонентная модель.

Задача книги — показать, как использовать эти возможности осознанно и строить интерфейсы, опираясь прежде всего на саму веб-платформу.

Вы разберётесь, как:

- проектировать документы на основе семантики и понятной структуры;
- использовать нативные HTML-механизмы вместо избыточного JavaScript;
- создавать доступные формы и интерактивные интерфейсы;
- управлять загрузкой ресурсов и критическим путём рендеринга;
- применять современные браузерные API с учётом поддержки браузерами;
- строить переиспользуемые компоненты на Web Components;
- проектировать интерфейсы с Progressive Enhancement;
- учитывать HTML при разработке SSR-приложений и современных архитектур.

## Для кого эта книга

- Для frontend-разработчиков, которые хотят глубже понимать платформу, на которой работают их инструменты.
- Для разработчиков, переходящих от фреймворк-центричного подхода к использованию нативных возможностей браузера.
- Для инженеров, проектирующих дизайн-системы, Web Components и долгоживущие интерфейсные платформы.
- Для тех, кто хочет принимать архитектурные решения на основе стандартов и реальных возможностей браузеров.

Предварительное знакомство с HTML и базовыми принципами CSS и JavaScript будет полезно. Книга не привязана к конкретному фреймворку.

## Основной принцип

**Сначала возможности веб-платформы — затем дополнительный JavaScript и библиотеки, если они действительно необходимы.**

Современный HTML не отменяет CSS, JavaScript или фреймворки. Он позволяет точнее определить, какие задачи уже решает браузер, и не создавать поверх платформы лишние уровни сложности.
