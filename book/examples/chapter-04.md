## 💻 Примеры: Элемент `<dialog>`

В этой главе мы рассмотрим практическую реализацию нативных диалоговых окон. Благодаря тому, что элемент `<dialog>` стал частью **Baseline Widely available** с марта 2022 года, его можно уверенно использовать в современных веб-проектах без тяжелых внешних библиотек.

### 1. Модальное и немодальное состояния

Браузер поддерживает два принципиально разных режима отображения диалога, которые вызываются соответствующими методами JavaScript.

- **Модальное (`showModal()`):** Блокирует взаимодействие с остальной страницей, делая её **инертной** (`inert`). Окно автоматически центрируется и помещается в **Top Layer** (верхний слой), перекрывая любые `z-index`.
- **Немодальное (`show()`):** Позволяет пользователю продолжать работу с основным контентом страницы.

```html
<!-- Базовая разметка -->
<dialog id="infoDialog">
  <p>Это нативное окно сообщения.</p>
  <button onclick="infoDialog.close()">Закрыть</button>
</dialog>

<!-- Кнопки управления -->
<button onclick="infoDialog.showModal()">Открыть модально</button>
<button onclick="infoDialog.show()">Открыть немодально</button>
```

### 2. Закрытие через формы и `returnValue`

Одной из самых мощных функций `<dialog>` является интеграция с формами. Если установить атрибут **`method="dialog"`**, отправка формы автоматически закроет окно без необходимости писать JavaScript-обработчик.

```html
<dialog id="confirmDelete">
  <form method="dialog">
    <p>Удалить этот файл навсегда?</p>
    <button value="cancel">Отмена</button>
    <!-- autofocus переносит фокус на кнопку подтверждения при открытии -->
    <button value="confirm" autofocus>Да, удалить</button>
  </form>
</dialog>

<button onclick="confirmDelete.showModal()">Удалить файл</button>

<script>
  confirmDelete.addEventListener('close', () => {
    // Свойство returnValue содержит значение нажатой кнопки
    if (confirmDelete.returnValue === 'confirm') {
      console.log('Файл удален');
    } else {
      console.log('Действие отменено');
    }
  });
</script>
```

### 3. Нативная доступность (A11y)

Элемент `<dialog>` берет на себя основные задачи доступности: навигацию по Tab внутри окна и закрытие по клавише **Esc** (для модальных окон). Разработчик обязан предоставить доступное имя окна с помощью ARIA-атрибутов.

```html
<!-- Использование aria-labelledby связывает окно с его заголовком -->
<dialog id="settingsDialog" aria-labelledby="dialogTitle">
  <h2 id="dialogTitle">Настройки профиля</h2>
  <label>Имя: <input type="text" name="username" /></label>
  <button onclick="settingsDialog.close()">Сохранить</button>
</dialog>
```

### 4. Современное «Легкое закрытие» (Light Dismiss)

В новых версиях стандарта (2024–2026) появился атрибут **`closedby`**, который позволяет декларативно настроить способы закрытия окна пользователем.

- `closedby="any"`: Закрывает окно при нажатии Esc или клике вне области диалога.
- `closedby="none"`: Запрещает автоматическое закрытие; окно можно закрыть только программно или через кнопку.

```html
<!-- Окно закроется при клике по фону (backdrop) -->
<dialog id="promoDialog" closedby="any">
  <h3>Специальное предложение!</h3>
  <p>Только сегодня скидка 50%.</p>
  <button onclick="promoDialog.close()">Понятно</button>
</dialog>
```

### 5. Стилизация фона (`::backdrop`)

Для визуального отделения модального окна от инертного контента используется специальный псевдоэлемент **`::backdrop`**. Он позволяет затемнить или размыть всё, что находится «под» диалогом.

```css
/* Стили для фона модального окна */
dialog::backdrop {
  background-color: rgba(0, 0, 0, 0.6);
  backdrop-filter: blur(5px); /* Создает эффект размытого стекла */
}

/* Стили самого окна */
dialog {
  border: none;
  border-radius: 8px;
  padding: 20px;
  box-shadow: 0 4px 15px rgba(0, 0, 0, 0.2);
}
```

### 6. Вложенные диалоги

Стандарт позволяет открывать одно модальное окно поверх другого. В этом случае новое окно создается выше в стеке Top Layer. Клавиша Esc закроет только самое верхнее (последнее открытое) окно.

```html
<dialog id="firstDialog">
  <p>Первый уровень</p>
  <button onclick="secondDialog.showModal()">Открыть второй</button>
  <button onclick="firstDialog.close()">Закрыть всё</button>
</dialog>

<dialog id="secondDialog">
  <p>Второй уровень</p>
  <button onclick="secondDialog.close()">Закрыть второй</button>
</dialog>
```

Эти примеры подтверждают, что `<dialog>` является полноценным системным компонентом, который обеспечивает высокую производительность и безупречную доступность «из коробки».
