Ниже приведен список ссылок на источники и разделы спецификаций для **Главы 18. HTML Templates**.

### Элемент `<template>` и фрагменты документа

Элемент **`<template>`** служит механизмом для объявления фрагментов HTML, которые не отображаются при загрузке страницы, но могут быть активированы позже с помощью JavaScript.

- **HTML Standard: Section 4.12.3 The `template` element** — техническая спецификация элемента, его категорий и модели содержимого.
- **MDN: `<template>`: The Content Template element** — описание элемента как основы для структур веб-компонентов.
- **HTML Standard: Template contents** — описание ассоциированного объекта `DocumentFragment`, который хранит содержимое шаблона.
- **HTML Standard: Inert template document** — механизм, обеспечивающий «инертность» содержимого шаблона: скрипты внутри него не выполняются, а ресурсы не загружаются до момента клонирования.

### Элемент `<slot>` и распределение контента

**Слоты** позволяют создавать гибкие интерфейсы, предоставляя места для вставки внешней разметки в структуру компонента.

- **HTML Standard: Section 4.12.4 The `slot` element** — определение элемента слота и его программного интерфейса.
- **MDN: Web Components — HTML slots** — практическое руководство по использованию слотов для создания отдельных деревьев DOM.
- **HTML Standard: Slot assignment** — алгоритмы назначения элементов слотам на основе атрибута `name`.
- **DOM Standard: Section 4.2.2.1 Slots** — низкоуровневое определение слотов и алгоритмов обновления их имен.

### Повторное использование и клонирование (Cloning)

Основная мощь шаблонов заключается в возможности их **многократного использования** путем создания копий их содержимого.

- **HTML Standard: Cloning steps for `template`** — специфические правила клонирования, обеспечивающие корректное копирование внутреннего фрагмента документа.
- **HTML Standard: Example of populating a table** — пример использования шаблона для динамического заполнения таблицы данными без ручного создания DOM-узлов в JS.
- **DOM Standard: `cloneNode()` and `importNode()`** — описание методов, используемых для дублирования содержимого шаблонов перед их вставкой в основной документ.

### Серверный рендеринг (Server-Side Rendering)

Современный HTML позволяет использовать шаблоны для **декларативного определения Shadow DOM**, что значительно улучшает производительность приложений с серверным рендерингом.

- **MDN: Declaratively with HTML (Shadow DOM)** — объяснение того, как атрибут `shadowrootmode` у элемента `<template>` позволяет браузеру отрисовывать теневое дерево немедленно при парсинге HTML.
- **HTML Standard: Streaming declarative shadow roots** — спецификация атрибутов управления (например, `shadowrootclonable`), которые определяют свойства создаваемого на сервере теневого корня.

Использование этих нативных механизмов позволяет создавать **инкапсулированные и производительные интерфейсы**, минимизируя зависимость от тяжелых клиентских фреймворков.
