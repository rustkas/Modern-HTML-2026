Для **Главы 20**, посвященной критическому пути рендеринга (**Critical Rendering Path**), основными источниками являются руководство по производительности MDN и соответствующие разделы стандарта HTML, описывающие парсинг и модель отрисовки.

Ниже приведен список ссылок на разделы источников, сгруппированный по вашим темам:

### Общие сведения о Critical Rendering Path
*   **MDN Guide: Critical rendering path** — определение последовательности шагов (DOM, CSSOM, Render Tree, Layout, Paint), которые браузер проходит для превращения кода в пиксели.
*   **MDN Guide: How browsers work** — подробный обзор процесса наполнения страницы контентом и взаимодействия различных механизмов браузера.

### HTML Parser (Парсинг)
*   **HTML Standard: Section 13.2 Parsing HTML documents** — фундаментальное описание модели парсинга HTML-документов.
*   **HTML Standard: Section 13.2.5 Tokenization** — технические детали процесса токенизации (превращения байтов в теги и контент).
*   **HTML Standard: Section 13.2.6 Tree construction** — алгоритмы построения дерева DOM из полученных токенов.
*   **HTML Standard: Section 13.2.8 Speculative HTML parsing** — описание механизма спекулятивного парсинга для ускорения загрузки внешних ресурсов.

### CSSOM и Render Tree
*   **MDN Glossary: CSSOM** — определение объектной модели CSS.
*   **HTML Standard: Section 3.1.6 Render-blocking mechanism** — описание того, как таблицы стилей и скрипты могут блокировать процесс формирования дерева отрисовки.
*   **HTML Standard: Interactions of styling and scripting** — технические детали взаимодействия CSSOM с исполнением JavaScript-кода.

### Layout (Макетирование)
*   **MDN Glossary: Cumulative Layout Shifts (CLS)** — информация о метрике стабильности макета, напрямую связанной со стадией Layout.
*   **HTML Standard: Section 15 Rendering** — правила отрисовки и макетирования различных типов элементов (блочных, строчных, таблиц и т.д.).

### Paint и Composite (Отрисовка и Композиция)
*   **MDN Glossary: First contentful paint (FCP)** — описание ключевой стадии отрисовки первого значимого контента.
*   **MDN Guide: CSS and JavaScript animation performance** — анализ того, как различные свойства влияют на стадии Paint и Composite, и преимущества использования композитных слоев для анимации.
*   **HTML Standard: Section 4.12.5.1.22 Drawing model** — детальное описание последовательности шагов при отрисовке элементов (на примере Canvas, что иллюстрирует общие принципы слоев и фильтров).
*   **HTML Standard: Section 4.12.5.1.17 Compositing** — определение операторов композиции и смешивания слоев.

Эти источники предоставляют полную техническую базу для понимания того, как браузер оптимизирует доставку и отображение контента пользователю.
