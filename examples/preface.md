### От HTML4 к HTML Living Standard
Переход к модели **Living Standard** позволил внедрять инновации непрерывно, не дожидаясь выпуска фиксированных версий, как это было с HTML4. 
*   **Пример с `<dialog>`:** Элемент `<dialog>` для создания модальных окон стал широко доступен в браузерах в 2022 году. Стандарт продолжает развиваться: например, в 2026 году в спецификацию были внесены уточнения для атрибута `closedby`, который определяет способы закрытия окна пользователем (кликом вне области или клавишей Esc).
*   **Пример с кодировкой:** В отличие от старых стандартов, современный HTML жестко требует использования **UTF-8**, что устраняет ошибки при передаче данных в формах и URL.

### Почему современные фреймворки не заменяют HTML
Фреймворки лишь надстраиваются над HTML, который остается фундаментом для **доступности (Accessibility)** и **производительности**.
*   **Семантика против JavaScript:** Вместо того чтобы создавать сложные компоненты на JavaScript для раскрывающихся списков, разработчики теперь могут использовать нативный элемент **`<details>`** с заголовком **`<summary>`**. Это работает без единой строки JS-кода и автоматически понятно экранным дикторам.
*   **Нативные кнопки:** Использование стандартного тега **`<button>`** вместо `<div>` с обработчиком клика гарантирует, что элемент будет доступен с клавиатуры (через Tab) и корректно передаст свою роль вспомогательным технологиям без дополнительных ARIA-атрибутов.

### HTML как часть Web Platform
HTML интегрирован с DOM, Fetch и CSS, образуя единую **Web Platform**.
*   **Web Components:** С помощью элементов **`<template>`** и **`<slot>`** разработчики создают собственные теги (например, `<my-card>`), которые инкапсулируют стили и логику внутри **Shadow DOM**. Это позволяет изолировать компоненты: стили основной страницы не «протекают» внутрь компонента, и наоборот.
*   **Интеграция с API:** HTML-атрибуты теперь напрямую управляют сложным поведением браузера. Например, атрибут **`crossorigin`** на тегах `<img>` или `<video>` настраивает CORS-запросы для работы с изображениями на холсте (`canvas`).

### Что изменилось за последние десять лет
Последнее десятилетие принесло в HTML функции, которые раньше требовали тяжелых библиотек.
*   **Popover API (2025):** Новый глобальный атрибут **`popover`** позволяет создавать всплывающие подсказки и меню, которые автоматически отображаются поверх всех остальных элементов (в «верхнем слое» документа) и поддерживают «легкое закрытие» (light dismiss) кликом вне области.
*   **Оптимизация загрузки:** Атрибут **`loading="lazy"`** для `<img>` и `<iframe>` позволяет браузеру не загружать ресурсы, пока пользователь не прокрутит страницу до них, что значительно ускоряет первую отрисовку.
*   **Приоритеты ресурсов:** Атрибут **`fetchpriority`** дает возможность явно указать браузеру, какие изображения или скрипты являются критически важными (например, LCP-изображение), а какие можно загрузить позже.
*   **Декларативный Shadow DOM:** Использование **`<template shadowrootmode="open">`** позволяет определять структуру Shadow DOM прямо в HTML-разметке, что критически важно для серверного рендеринга (SSR) и быстрой работы компонентов.
