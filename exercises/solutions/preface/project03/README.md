Механика работы этого примера построена на технологии **Web Components**, которая объединяет три главных стандарта: Custom Elements, Shadow DOM и HTML Templates.

Разбор работы ключевых частей компонента `<user-card>`:

### 1. Шаблон (`<template>`) и хранение разметки

Элемент `<template>` в HTML служит контейнером для разметки и стилей, которые **не отображаются браузером** при загрузке страницы, но могут быть клонированы с помощью JavaScript.

* Внутри шаблона находится вся структура карточки и тег `<style>` со стилями.
* Главное преимущество шаблона — он является «спящим» фрагментом кода, который ждет своей активации.

### 2. Создание класса и регистрация (Custom Elements)

Чтобы браузер понял новый тег `<user-card>`, мы создали класс `UserCard`, наследуемый от базового `HTMLElement`:

* **`super()`** в конструкторе обязательно вызывается для корректной инициализации родительского класса.
* Метод **`customElements.define('user-card', UserCard)`** регистрирует наш тег в глобальном реестре браузера. После этого любой тег `<user-card>` на странице автоматически превращается в экземпляр этого класса.

### 3. Инкапсуляция и Shadow DOM

Строка `this.attachShadow({ mode: 'open' })` создаёт для компонента **теневое дерево DOM** (Shadow DOM), которое скрыто от основного документа:

* **Изоляция стилей:** Стили, написанные внутри тега `<style>` в шаблоне (и даже селекторы вроде `p`), действуют **только** внутри этого компонента. Они не «утекают» наружу и не дают внешним стилям страницы случайно сломать дизайн карточки.
* **Режим `open**` означает, что JavaScript снаружи компонента может получить доступ к теневому дереву через свойство `element.shadowRoot`, если это потребуется.

### 4. Слоты (`<slot>`) и проекция контента

Теги `<slot>` выступают в роли «заглушек» или точек вставки, куда подставляется контент из внешнего HTML-документа:

* Когда мы пишем `<span slot="username">Алексей Смирнов</span>` внутри тега `<user-card>`, браузер берёт этот текст и **проецирует** его внутрь `<slot name="username">` внутри Shadow DOM.
* Именованные слоты (`name="..."`) позволяют чётко указывать, какой именно кусок внешнего текста или разметки должен попасть в конкретное место внутри шаблона. Если слот не заполнен, отобразится текст по умолчанию, указанный внутри тега `<slot>` в шаблоне.
