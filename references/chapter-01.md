# 📚 Источники для Главы 1

- [**DOM Standard (WHATWG)**](https://dom.spec.whatwg.org/) — основной стандарт, определяющий архитектуру дерева узлов (node tree) и концепцию «документа» как универсальной модели данных для любого контента или приложения.
- [**HTML Standard (WHATWG)**](https://html.spec.whatwg.org/multipage/) — спецификация, описывающая внутренний смысл (семантику) элементов HTML, отличия структуры от оформления и роль HTML в понимании контента поисковыми роботами и браузерами.
- [**MDN Web Docs: HTML**](https://developer.mozilla.org/en-US/docs/Web/HTML) — руководство по базовым строительным блокам веба, категориям контента и использованию микроданных для SEO.
- [**Accessible Rich Internet Applications (WAI-ARIA) 1.2**](https://www.w3.org/TR/wai-aria-1.2/) — стандарт доступности, объясняющий, как семантическая структура документа взаимодействует со вспомогательными технологиями (AT).
- [**ARIA Authoring Practices Guide (APG)**](https://www.w3.org/WAI/ARIA/apg/) — практические рекомендации по обеспечению доступности через использование семантических ориентиров (Landmarks) и нативных элементов.
- [**web.dev: Learn HTML**](https://web.dev/html) — обучающие материалы по использованию HTML как слоя структуры и семантики в рамках современной Web-платформы.
