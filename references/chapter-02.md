# 📚 Источники для Главы 2

- [**HTML Standard: Sections (WHATWG)**](https://html.spec.whatwg.org/multipage/sections.html) — спецификация, определяющая основные структурные элементы, такие как `<article>`, `<section>`, `<nav>`, `<aside>`, `<header>`, `<footer>` и `<address>`.
- [**HTML Standard: Grouping content (WHATWG)**](https://html.spec.whatwg.org/multipage/grouping-content.html) — подробное описание элементов для группировки контента, включая главный ориентир страницы `<main>`, контейнеры для иллюстраций `<figure>` и `<figcaption>`, а также правила использования элемента последнего средства `<div>`.
- [**HTML Standard: Text-level semantics (WHATWG)**](https://html.spec.whatwg.org/multipage/text-level-semantics.html) — описание элементов текстового уровня, включая элемент `<time>` для представления машиночитаемых дат и времени.
- [**WAI-ARIA 1.2: Landmark Roles**](https://www.w3.org/TR/wai-aria-1.2/#landmark_roles) — стандарт, объясняющий роль семантических элементов HTML как навигационных ориентиров (Landmarks) для вспомогательных технологий.
- [**MDN Web Docs: HTML elements reference**](https://developer.mozilla.org/en-US/docs/Web/HTML/Element) — справочное руководство по всем элементам HTML, их семантическому значению и примерам использования в современных браузерах.
- [**web.dev: Learn HTML (Semantics)**](https://web.dev/learn/html/semantic-html/) — обучающие материалы по применению семантической разметки для улучшения доступности и структуры документов.

### Ключевые разделы спецификации:

- **Элемент `<article>`**: определяется как автономная композиция, пригодная для независимого распространения.
- **Элемент `<section>`**: представляет тематическую группу контента, обычно с заголовком.
- **Элемент `<div>`**: официально классифицируется как элемент «последнего средства», используемый только при отсутствии подходящих семантических альтернатив.
- **Элемент `<address>`**: предназначен строго для контактной информации ближайшего предка-статьи или документа.
- **Элемент `<main>`**: обозначает доминирующее содержимое страницы и должен быть «иерархически правильным».
