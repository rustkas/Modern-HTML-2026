# 📚 Источники для Главы 3

- [**HTML Standard (WHATWG)**](https://html.spec.whatwg.org/) — основной «Живой стандарт», определяющий эволюцию языка, принципы обратной совместимости и переход от фиксированных версий к модели непрерывного обновления.
- [**MDN Web Docs: Popover API**](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API) — руководство по новому декларативному интерфейсу (Baseline 2025), который позволяет управлять всплывающими элементами через атрибуты `popover` и `popovertarget`.
- [**MDN Web Docs: <dialog> element**](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog) — описание нативного элемента для создания модальных и немодальных окон, ставшего широко доступным во всех браузерах с марта 2022 года.
- [**MDN Web Docs: Using shadow DOM**](https://developer.mozilla.org/en-US/docs/Web/API/Web_components/Using_shadow_DOM#declaratively_with_html) — раздел о **декларативном Shadow DOM**, объясняющий использование атрибута `shadowrootmode` в элементе `<template>` для инкапсуляции структуры через разметку.
- [**DOM Standard (WHATWG)**](https://dom.spec.whatwg.org/) — спецификация, описывающая архитектуру дерева узлов и API для манипуляции документами, на которых базируется взаимодействие HTML и JavaScript.
- [**web.dev: Learn HTML (Performance)**](https://web.dev/learn/html/performance/) — материалы по управлению производительностью через нативные атрибуты, такие как `loading="lazy"` для отложенной загрузки и `fetchpriority`.

### Ключевые термины и концепции:

- **HTML Living Standard**: модель развития, принятая в результате соглашения между WHATWG и W3C в 2019 году для обеспечения совместимости и соответствия реализациям.
- **Декларативный интерфейс**: подход, при котором разработчик описывает желаемое состояние (например, через атрибут `popover`), а браузер берет на себя реализацию логики (например, «легкое закрытие»).
- **Baseline (2022/2025)**: концепция определения готовности технологий для широкого использования в веб-продакшене.
