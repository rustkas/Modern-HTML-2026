# 📚 Источники для Главы 4

- [**HTML Standard: The `<dialog>` element (WHATWG)**](https://html.spec.whatwg.org/multipage/interactive-elements.html#the-dialog-element) — основной технический стандарт, определяющий алгоритмы работы методов `show()`, `showModal()` и `close()`, механизм инертности основного контента и работу атрибута `closedby`.
- [**MDN Web Docs: `<dialog>` element**](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/dialog) — подробное руководство по использованию элемента, стилизации фона через `::backdrop` и управлению возвращаемым значением через форму с `method="dialog"`.
- [**WAI-ARIA 1.2: dialog role**](https://www.w3.org/TR/wai-aria-1.2/#dialog) — спецификация доступности, описывающая требования к «доступному имени» (accessible name) и поведению вложенных окон.
- [**ARIA Authoring Practices Guide (APG): Dialog (Modal) Pattern**](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) — рекомендации W3C по проектированию модальных окон, управлению фокусом и навигации с клавиатуры.
- [**web.dev: Baseline**](https://web.dev/baseline) — информация о статусе поддержки элемента `<dialog>` (входит в Baseline с марта 2022 года).

### Ключевые технические аспекты:
*   **Управление фокусом**: браузер автоматически перемещает фокус на первый подходящий элемент при открытии и возвращает его на место при закрытии.
*   **Инертность (Inertness)**: при открытии модального диалога через `showModal()` весь остальной документ становится недоступным для взаимодействия на уровне браузера.
*   **Топ-слой (Top Layer)**: модальные окна всегда отображаются поверх всех остальных элементов, игнорируя значения `z-index`.
*   **Типичные ошибки**: спецификация прямо запрещает использование атрибута `tabindex` на самом элементе `<dialog>` и предостерегает от ручного удаления атрибута `open`.
