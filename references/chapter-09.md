Для **Главы 9**, посвященной доступности форм и пользовательскому вводу, основными источниками являются спецификация HTML (Living Standard) в разделах, касающихся элементов группировки и подписей, а также спецификации WAI-ARIA 1.2 и APG, описывающие динамические обновления и навигацию.

Ниже приведен список ссылок на разделы источников:

### Элементы Label, Fieldset и Legend
*   **HTML Standard: Section 4.10.4 The `label` element** — описание элемента подписи и его связи с элементами управления через атрибут `for`.
*   **HTML Standard: Section 4.10.15 The `fieldset` element** — использование элемента для тематической группировки набора элементов управления.
*   **HTML Standard: Section 4.10.16 The `legend` element** — определение заголовка (caption) для содержимого родительского `fieldset`.
*   **WAI-ARIA 1.2: Section 6.7 `aria-labelledby` property** — программный способ связывания элемента с его текстовой подписью.

### Сообщения об ошибках (Error Messages)
*   **WAI-ARIA 1.2: Section 6.7 `aria-errormessage` property** — идентификация элемента, содержащего сообщение об ошибке для конкретного объекта.
*   **HTML Standard: Section 4.10.21.1 Custom validity error message** — механизмы определения и отображения пользовательских сообщений о невалидности ввода.
*   **WAI-ARIA 1.2: Section 6.7 `aria-invalid` state** — индикация того, что введенное значение не соответствует ожидаемому формату.

### Живые регионы (Live Regions)
*   **WAI-ARIA 1.2: Definition of Live Region** — описание областей страницы, которые обновляются динамически без необходимости перемещения фокуса пользователя.
*   **WAI-ARIA 1.2: Section 6.7 `aria-live` property** — управление приоритетностью объявлений вспомогательных технологий (`polite`, `assertive`).
*   **WAI-ARIA 1.2: Section 5.3.5 Live Region Roles** — специализированные роли для живых регионов, такие как `alert`, `log`, `status` и `timer`.

### Клавиатурная навигация (Keyboard Navigation)
*   **HTML Standard: Section 6.6 Focus** — иерархия интерактивных виджетов и механизмы передачи ввода с клавиатуры активному элементу.
*   **HTML Standard: Section 6.6.5 Sequential focus navigation** — правила формирования порядка последовательной навигации по табуляции.
*   **HTML Standard: Section 6.6.3 The `tabindex` attribute** — управление включением элементов в порядок навигации и их последовательностью.
*   **WAI-ARIA 1.2: Section 4.3 Managing Focus** — рекомендации по управлению фокусом в сложных составных виджетах.
*   **WAI-ARIA 1.2: Section 6.7 `aria-activedescendant` property** — альтернативный метод управления фокусом внутри контейнеров.
