Ниже приведен список ссылок на основные разделы спецификаций и руководства для **Главы 12. Современная работа с изображениями**.

### Элементы `<picture>` и `<source>`

Эти элементы позволяют декларативно управлять выбором ресурсов в зависимости от характеристик устройства и поддержки форматов.

- **HTML Standard: Section 4.8.1 The `picture` element** — описание контейнера, предоставляющего несколько источников для вложенного элемента `img`.
- **HTML Standard: Section 4.8.2 The `source` element** — спецификация элемента для определения альтернативных наборов изображений и медиа-ресурсов.
- **HTML Standard: Section 4.8.4.3.7 Selecting an image source** — алгоритм выбора конкретного ресурса браузером внутри `<picture>`.

### Атрибуты `srcset` и `sizes` (Viewport-based selection)

Инструменты для предоставления браузеру информации о доступных вариантах изображения и их размерах в макете.

- **HTML Standard: Section 4.8.4.2.1 Srcset attributes** — правила синтаксиса и использования дескрипторов плотности пикселей (`x`) и ширины (`w`).
- **HTML Standard: Section 4.8.4.2.2 Sizes attributes** — определение условий (media conditions) для выбора ширины изображения.
- **HTML Standard: Section 4.8.4.3.11 Parsing a sizes attribute** — технические детали разбора атрибута браузером, включая поддержку ключевого слова `auto`.

### Форматы AVIF и WebP

Современные форматы с более эффективным сжатием по сравнению с JPEG.

- **HTML Standard: Section 4.8.4.1.1 Adaptive images** — примеры использования атрибута `type` в элементе `<source>` для выбора форматов, таких как WebP.
- **MDN Guide: Multimedia - images** — рекомендации по использованию современных форматов для оптимизации производительности.

### Оптимизация: `loading="lazy"` и `decoding="async"`

Атрибуты, напрямую влияющие на скорость загрузки страницы и плавность интерфейса.

- **HTML Standard: Section 2.5.7 Lazy loading attributes** — спецификация атрибута `loading`, включая состояния `lazy` и `eager`.
- **HTML Standard: Section 4.8.4.3.4 Decoding images** — описание атрибута `decoding` и разница между синхронным и асинхронным режимами обработки графики.
- **HTML Standard: Section 2.5.7.1 Intersection Observer** — механизм, с помощью которого браузер отслеживает приближение лениво загружаемых ресурсов к области видимости.

### Адаптивные изображения (Responsive Images)

Общая концепция и практические руководства.

- **MDN Guide: Using responsive images in HTML** — подробное учебное пособие по созданию изображений, адаптирующихся под экраны разного размера и разрешения.
- **HTML Standard: Section 4.8.4.1 Introduction (Images)** — обзор ситуаций, в которых необходимо использование нескольких ресурсов (pixel density, art direction, viewport-based selection).
- **HTML Standard: Requirements for providing alternative text** — правила заполнения атрибута `alt` для обеспечения доступности.
