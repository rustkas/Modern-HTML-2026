Ниже приведен список ссылок на источники и ключевые разделы спецификаций для **Главы 17. Shadow DOM**.

### Изоляция компонентов (Encapsulation)
**Shadow DOM** позволяет прикреплять скрытые деревья DOM к элементам, изолируя их внутреннюю структуру от JavaScript и CSS основной страницы.

*   **DOM Standard: Section 4.2.2 Shadow tree** — техническое определение теневого дерева, его корня и связи с «легким деревом» (light tree).
*   **DOM Standard: Section 4.8 Interface `ShadowRoot`** — спецификация интерфейса теневого корня и его свойств, таких как `mode`.
*   **MDN: Using shadow DOM — Encapsulation from JavaScript** — описание того, как элементы внутри Shadow DOM скрыты от методов вроде `querySelectorAll()`.
*   **HTML Standard: Section 4.13.7.2 Shadow root access** — механизмы доступа к теневому корню через `ElementInternals`.

### Slot (Слоты и распределение контента)
**Слоты** являются заполнителями внутри компонента, которые разработчик может заполнить собственной разметкой.

*   **DOM Standard: Section 4.2.2.1 Slots** — определение элемента `slot`, его имени и алгоритма назначения узлов.
*   **HTML Standard: Section 4.12.4 The `slot` element** — описание использования элемента `slot` в теневом дереве и события `slotchange`.
*   **DOM Standard: Section 4.2.2.2 Slottables** — определение объектов (элементов и текстовых узлов), которые могут быть помещены в слоты.
*   **MDN: Web Components — HTML slots** — практическое руководство по использованию атрибута `slot` для распределения контента.

### Template (Шаблоны)
Элемент **`<template>`** позволяет объявлять фрагменты HTML, которые не рендерятся при загрузке, но могут быть клонированы скриптом.

*   **HTML Standard: Section 4.12.3 The `template` element** — фундаментальное описание элемента и его содержимого.
*   **HTML Standard: Appropriate template contents owner document** — алгоритм управления инертным документом, владеющим содержимым шаблона.
*   **MDN: Web Components — HTML templates** — описание того, как шаблоны служат основой для структуры веб-компонентов.

### Styling (Стилизация и селекторы)
Стили внутри Shadow DOM ограничены этим деревом, что предотвращает конфликты с глобальными стилями страницы.

*   **MDN: Applying styles inside the shadow DOM** — обзор программного и декларативного способов применения стилей.
*   **MDN: Constructable stylesheets** — использование `CSSStyleSheet` и `adoptedStyleSheets` для совместного использования стилей между компонентами.
*   **MDN: CSS pseudo-classes (`:host`, `:host()`, `:host-context()`)** — специализированные селекторы для стилизации теневого хоста.
*   **MDN: CSS pseudo-elements (`::part`, `::slotted`)** — инструменты для стилизации конкретных частей компонента извне и распределенного контента внутри слотов.

### Accessibility (Доступность)
Shadow DOM интегрирован в общую модель доступности, обеспечивая корректное взаимодействие вспомогательных технологий с изолированным контентом.

*   **WAI-ARIA 1.2: Section 7 Accessibility Tree** — описание того, как дерево доступности строится параллельно с деревом DOM, включая теневые структуры.
*   **HTML Standard: Section 4.13.7.4 Accessibility semantics** — использование `ElementInternals` для задания ролей и состояний ARIA внутри компонентов.
*   **DOM Standard: Retargeting algorithm** — алгоритм переназначения целей событий, который важен для сохранения логики взаимодействия при прохождении границ Shadow DOM.
*   **HTML Standard: Focus navigation owner** — правила определения порядка навигации с клавиатуры (tab order) через границы теневых деревьев.
